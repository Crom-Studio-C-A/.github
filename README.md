Crom Studio Venezuela es una organización tecnológica dedicada al desarrollo de software, APIs, herramientas empresariales, infraestructura y proyectos digitales.

Aquí publicamos proyectos, documentación, ejemplos de integración, herramientas para desarrolladores y recursos relacionados con nuestras diferentes iniciativas tecnológicas.

Áreas principales
Desarrollo de software
APIs REST
Odoo ERP
Linux e infraestructura
SMS y automatización
Datos abiertos
GTFS y transporte público
Herramientas para desarrolladores

Nuestros proyectos incluyen recursos para integrar servicios de Crom Studio y proyectos públicos orientados al ecosistema tecnológico venezolano.
