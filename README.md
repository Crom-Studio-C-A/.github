Crom Studio Venezuela es una organización tecnológica enfocada en crear soluciones empresariales, APIs robustas y mantener infraestructura de alto rendimiento. En este espacio compartimos nuestros proyectos de código abierto, herramientas para desarrolladores, ejemplos de integración y recursos para la comunidad, con un interés particular en aportar al entorno tecnológico venezolano.

## 🚀 Áreas de Especialidad

*   **Desarrollo y Sistemas:** Creación de aplicaciones a medida, diseño de APIs REST y herramientas para desarrolladores.
*   **Gestión Empresarial:** Desarrollo, personalización e integración de ecosistemas **Odoo ERP**.
*   **Infraestructura y Redes:** Administración de servidores **Linux**, despliegues de alta disponibilidad y gestión de servicios.
*   **Comunicaciones:** Automatización de procesos y servicios de integración SMS.
*   **Datos Abiertos:** Mantenimiento y publicación de repositorios **GTFS** para el transporte público de Venezuela.

## 🛠️ Tecnologías que utilizamos

*   **Lenguajes:** PHP, Python, JavaScript
*   **Bases de Datos:** MySQL, MariaDB
*   **Infraestructura & DevOps:** Linux (Debian), Docker, Nginx, Cloudflare
*   **Plataformas:** Odoo
